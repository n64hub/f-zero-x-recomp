An icon of its own. Like v0.1.4 it contains no game data: you need your own ROM of the USA release's first version (*F-Zero X (U)*, `CFZE`, a big-endian `.z64` of 16 MiB, SHA-1 `5f658e88ffa9de23cba6986a8fd3d3a90d7b4340`). Other regions, revisions and the 64DD's Expansion Kit are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `FZeroXRecompiled-v0.1.5-windows-x64.zip` and run `FZeroXRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `FZeroXRecompiled-v0.1.5-linux-x64.tar.gz` and run `FZeroXRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **An icon of its own:** the game has its own icon, a hover racer on a glowing track at dusk, drawn for the project (nothing in it comes from the game). It shows on the program in Explorer and the taskbar, on the game's window (on Linux too, where the window had no icon before) and beside the game in the launcher's menu. Before it was a text tile with the game's initials.

The [README](https://github.com/n64hub/f-zero-x-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#f-zero-x).
