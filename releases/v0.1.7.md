A fix for quitting on Linux, from the shared frontend. Like v0.1.6 it contains no game data: you need your own ROM of the USA release's first version (*F-Zero X (U)*, `CFZE`, a big-endian `.z64` of 16 MiB, SHA-1 `5f658e88ffa9de23cba6986a8fd3d3a90d7b4340`). Other regions, revisions and the 64DD's Expansion Kit are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `FZeroXRecompiled-v0.1.7-windows-x64.zip` and run `FZeroXRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `FZeroXRecompiled-v0.1.7-linux-x64.tar.gz` and run `FZeroXRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Quits at once on Linux when asked to:** logging out, a session timeout or Ctrl+C in the terminal that started it now quits the game at once. Before, it opened a quit prompt nobody could answer, and the game only ended when it was killed. Closing the window still asks first.

The [README](https://github.com/n64hub/f-zero-x-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#f-zero-x).
